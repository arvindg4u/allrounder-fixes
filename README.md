# allrounder-fixes
Collection of practical fixes and scripts

## Skills

| Skill | What it does |
|---|---|
| [pdf-paper-solver](skills/pdf-paper-solver) | Solves an exam/question-paper PDF end-to-end and produces **one Obsidian Flavored Markdown note** — wikilinked answer key, per-question callouts, web-verified explanations with sources, and a revision checklist. Single agent (no subagents), and each scanned page is read **exactly once** into a page-wise notes bank before any solving starts. Maths/reasoning answers are shown with a second independent verification method. Install: `bash skills/pdf-paper-solver/install.sh` · Use: `/solve-paper <paper.pdf>` |
